# 从解题展示到教学讲解

先写出并验算完整题解，再设计动画。一个讲解视频应回答“为什么选择这条路”，而不仅是报出下一条公式。生物题还应演出“哪个结构发生了什么变化，怎样导致结果”；具体画法见 [biology-visuals.md](biology-visuals.md)。

## 先让观众看见一个值得追问的现象

- 开头直接给出具体变化和一个清楚的问题，例如“坏掉的线粒体，细胞怎样清理？”。随后带观众找到答案。问题必须由本课解决，不能用与教学无关的悬念骗取观看。
- 先展示关键对象与变化，再引入理解它所需的概念。逐条念完整题干、先列所有术语、长片头和课程目录会推迟真正的解释。
- 一句旁白对应一个主要动作。完成“观察 → 解释 → 证据 → 结论”，避免同一句结论同时出现在配音、整段字幕、板书和装饰卡片里。
- 让观众有机会预测下一步，例如包裹膜尚未闭合时问“现在可以开始降解了吗？”，再用闭合、融合和内部降解回答。不能编造学生的回应或把预设动画称为真实互动。

吸引力服务于理解。可以用明确的问题、看得见的变化和及时揭晓来提高可看性；不能保证平台关注、传播量或学习效果，也不能填写未经测量的完成率、提升百分比或学生反馈。

## 学习节奏

- 独立大题优先拆成分题视频，各自保留问题、必要概念、关键推理和完整答案。基础薄弱的观众需要解释概念，但不需要反复听同一句结论。不要为了固定时长跳过推理。
- 每句只讲一个推理步骤；先解释关键概念，再使用它。统计题先解释柱形面积才是频率；线面角先找投影，再算角。
- 在真正需要思考的关键问题后设置 `pause_after`，下一句再揭示答案。系统增加真实的无旁白时间，并保留问题字幕。完整课可按问题难度安排约 2~4 秒；短样片只保留必要的短停顿。需要长时间计算时提示观众自行暂停，不给每句机械地加长停顿。
- 结尾只回顾最关键的因果链或方法。适合迁移的课可换一个条件让学生再算或预测，并说明答案及适用条件；不要为了模板完整重复整段讲解。

## 样片审阅后再批量导出

先完成约 45~60 秒、覆盖一个完整解释过程的样片。用真实配音时长检查开头、术语、镜头与机制，再决定是否扩展整课。样片应同时满足：问题具体、画面能解释、因果正确、最终能回答开头的问题。

先审讲稿与低成本预览，再进行高成本视频导出。发现基本机制或图表指标错误时先修正源文件，不批量生成有相同问题的课程。多个完整小问不强塞进 60 秒样片；样片只验证表现方式，完整课程仍须覆盖用户要求的题目。

## 生物题的证据边界

- 明确区分题目实测、机制示意与据此作出的推断。动画中有多少颗粒、发生得多快，不能当作原题数据。
- 正确引用指标。例如活性氧含量的柱形图不能被解释为直接测量的存活率；保护细胞的解释要说明依据。
- 连续演出原因、中间环节与结果。不能用“减少”“增强”的结论卡代替运输、包裹、融合或降解。
- 比喻之后恢复科学名称和条件；不让拟人化故事改变膜结构、反应场所、物质方向或耗能环节。

## 定理条件与依据

使用定理的那一句可声明 `theorem`，列明每个条件及其依据。`--check` 会要求这些字段完整，并输出 `build/teaching_report.txt`。

```json
{
  "zh": "条件满足，使用勾股定理求斜边。",
  "tts": "条件满足，使用勾股定理求斜边。",
  "en": "The conditions hold, so use Pythagoras.",
  "theorem": {
    "name": "勾股定理",
    "conditions": [
      {"claim": "∠C = 90°", "reason": "题目已知"},
      {"claim": "AB 是斜边", "reason": "AB 对着直角 C"}
    ],
    "conclusion": "AB^2 = AC^2 + BC^2"
  }
}
```

这是**结构检查，不是数学证明验证器**。它不会自动识别未声明的定理，也不会验证条件或结论是否真实。必须独立验算、核对报告，并把条件在 `anim.js` 的板书和图形中展示出来。报告不会自动绘制到画面。

例如用“两条线垂直”证明“线与面垂直”时，必须说明这两条线都在该平面内、相交，并且待证直线垂直于两者。只写“垂直”不够。

## 动画审阅

像素变化只说明画面在动，不能证明动画有教学意义。`motion` 仍只采样旁白段（`start` 到 `end`），不会把有意静止的思考停顿判为失败。人工审阅时检查：

1. 图形是否把当前推理关系演出来，而不是无意义晃动。
2. 辅助线与投影是否来自同一几何模型；垂足、角度和长度是否计算正确。
3. 条件、定理和结论的出现顺序是否与旁白一致。
4. 停顿期间问题是否保留，答案是否留到下一句才出现。
5. 迁移题是否满足定理的条件；改变条件后是否仍可使用原方法。
6. 生物机制是否来自同一细胞模型，结构、空间、膜内外关系和过程顺序是否连贯；按 [biology-visuals.md 的审查清单](biology-visuals.md#视觉与因果审查清单) 核对。
7. 开场提出的问题是否最终回答；文字、回顾和停顿是否有重复，可以删掉而不影响推理。

自带斜边中线模板演示了条件核对、两次思考停顿、矩形判定的中间理由，以及斜边改为十的迁移题。
