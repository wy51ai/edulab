# 生物机制的具体可视化

目标是让观众看清“哪种结构，在哪里，发生了什么变化，因此怎样影响结果”。细胞模型承担解释，文字记录名称和结论。模型可以是有层次的二维剖面或简化立体模型，不要求真人教师或交互平台。

## 镜头必须建立空间关系

使用同一套模型完成 **整体 → 局部 → 机制变化 → 回到整体**：

1. 先给出完整细胞，标出本课对象在细胞内或细胞膜上的位置。
2. 相机向该对象靠近，保留细胞轮廓或小型定位图，让观众知道局部来自哪里。
3. 放大后演出实际的结构变化或运输过程。相机稳定下来再讲关键动作。
4. 拉回原来的细胞，看变化如何影响整体，再对应题目证据与答案。

同一对象使用固定 ID、颜色和形态特征；缩放与镜头改变不重建另一套布局。剖面、遮挡和前后层次来自同一模型。将物体移出视野后再回到整体时，它的位置和状态必须接得上。为讲清机制而放大的颗粒、减慢的过程或固定的细胞器布局，应说明是教学示意。

## 结构清单与模型差异

| 对象 | 必须能辨认的结构 | 容易画错的地方 |
|---|---|---|
| 动物细胞 | 细胞膜、细胞质区域、细胞核；按本课需要显示线粒体和溶酶体 | 不额外添加细胞壁或叶绿体；通用动物细胞剖面不冒充 PC12 的真实显微形态 |
| 植物细胞 | 细胞壁在细胞膜外；按组织和题意显示液泡、叶绿体等 | 根细胞不为了“像植物”而统一添加叶绿体；植物降解过程按题意使用液泡，不能直接套用动物细胞溶酶体模型 |
| 酵母 | 真核细胞、细胞壁与细胞膜、线粒体、液泡；相关题目中显示脂滴 | 酵母是单细胞真菌，不画叶绿体；脂滴不是液泡，不把脂滴画成双膜细胞器 |
| 细胞膜局部 | 连贯的磷脂双分子层，嵌入膜中的运输蛋白；膜内外有明确标记 | “磷脂双分子层”是一层生物膜，不等于两层生物膜；颗粒不能从任意位置穿膜 |
| 线粒体 | 外膜、内膜及其形成的嵴；膜间隙和内膜围成的基质 | 内膜不是几条游离波浪线；不得把基质与细胞质基质混为一处 |
| 溶酶体 | 单膜围成的内部空间；与自噬体融合后显示内部降解 | 不把溶酶体画成从外面咬碎线粒体的怪物，也不把“相遇”当作已经“融合” |

基础结构的核对依据见 [OpenStax：真核细胞](https://openstax.org/books/biology-2e/pages/4-3-eukaryotic-cells)。只核对事实，图形由项目自行绘制。

## 一句旁白，对应一个可追踪的变化

每句先确定观众要看见的变化，再写旁白。运输必须演出“起点 → 膜蛋白或路径 → 终点”；包裹必须演出“开放 → 延伸 → 闭合”。只让线粒体呼吸般缩放、颗粒随意飘动或标签跳出来，不算机制动画。

标签贴着结构，用引线连接，复杂镜头同时保留少量关键标签。颜色可帮助识别，但还要有形态、名称或符号，不能只靠红绿区分。背景细胞器降低对比度，当前动作保持清晰。不同分子、离子与细胞器不共用一个无标识的圆点。

比喻用于引出问题，随后恢复科学名称。例如“细胞怎样清理坏掉的线粒体？”可以开场；“溶酶体负责降解”是解释。不要用拟人意图代替机制，不能说细胞“决定牺牲自己”而没有题目或资料依据。

## 线粒体自噬：必须保留的顺序

本示例讲的是动物细胞中由自噬体运送线粒体的宏自噬途径。并非所有自噬途径都采用相同画法，不应外推到全部细胞或全部低氧条件。

| 阶段 | 画面必须演出 | 旁白要说明 | 不允许的省略 |
|---|---|---|---|
| 定位 | 整体细胞中找到目标线粒体，再进入其局部 | 当前看的是哪颗线粒体 | 无过渡地换成一颗新线粒体 |
| 包裹 | 隔离膜沿线粒体周围延伸，开口逐渐缩小 | 膜在包裹目标 | 用现成圆圈淡入代替包裹 |
| 闭合 | 开口真正合拢，形成包住线粒体的双膜自噬体 | 被包住的对象与自噬体膜是不同结构 | 将线粒体自身的双膜当成自噬体双膜 |
| 融合 | 闭合自噬体靠近溶酶体，外层膜与溶酶体膜融合，建立内部空间的连续性 | 接下来在内部发生降解 | 两个圆简单重叠，或未闭合就宣布完成融合 |
| 降解 | 在融合后的内部空间，逐步显示自噬体内膜和线粒体结构被分解 | 降解发生在内部 | 线粒体在外面爆炸，或整颗瞬间消失 |
| 回到整体 | 返回同一细胞，保留健康线粒体与被清理位置 | 清除受损线粒体可限制相关活性氧的积累 | 清理一颗就宣称所有活性氧归零 |

双膜自噬体、与溶酶体融合的机制可核对 [Nguyen 等的原始研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC5166504/)；内层自噬体膜的降解可核对 [Tsuboyama 等的原始研究](https://pubmed.ncbi.nlm.nih.gov/27885029/)。只采用本课需要的机制层次，不将某条研究中特定分子通路强加到未给出该通路的题目。

ROS 颗粒和数量变化只能标为“机制示意”。清理后减少从目标线粒体发出的示意颗粒，是帮助理解来源减少，不是题目实测数量，也不能据此计算清除率。不要把所有 ROS 都归因于这一颗线粒体。

## 原题证据与机制动画分开说清

对于低氧 PC12 题，先确认图的指标：图 1 是线粒体自噬水平，图 2 是活性氧含量。比较图 2 时，必须在同一氧浓度下比较对照与 3-MA 处理。若没有存活率数据，不得把图 2 的柱子重新命名为存活率。

机制动画解释“为什么清除受损线粒体可能限制 ROS 积累”；题图提供“在题给条件下，这些组的指标如何变化”。保护细胞或有利于存活是结合题干与证据得出的解释，不能宣布图 2 直接测得了存活率提高。也不能把适度低氧的结论扩展为“氧越少越好”。

其他题目同样区分：题目给出的数据、一般背景机制、根据二者作出的推断。运输方向、耗能位置、膜内外关系与代谢发生场所必须逐项核对。

## 约 60 秒的样片先验证体验

样片先只讲清一个机制，例如“坏掉的线粒体，细胞怎样清理？”下面的时间是分镜预算，最终按实际旁白时长调整，不硬裁关键因果。

| 时间预算 | 镜头与动作 | 观众此刻能回答什么 |
|---|---|---|
| 0–5 秒 | 完整细胞中突出一颗受损线粒体与示意 ROS；提出清理问题 | 为什么要看下去？ |
| 5–12 秒 | 从整体靠近同一线粒体，保留细胞定位线索 | 我现在在细胞的哪里？ |
| 12–22 秒 | 展示隔离膜开始延伸，目标保持可见 | 什么结构在包裹它？ |
| 22–32 秒 | 膜继续延伸，开口合拢；短暂停留双膜截面 | 包裹完成后形成什么？ |
| 32–43 秒 | 自噬体移动到溶酶体旁，演出融合 | 怎样进入降解阶段？ |
| 43–53 秒 | 内部结构逐步分解，保留融合后的边界 | 线粒体在哪里被分解？ |
| 53–60 秒 | 回到原细胞与原问题，给出一句机制结论 | 这个过程为什么可能保护细胞？ |

按 [teaching-quality.md](teaching-quality.md) 和下面清单自审样片。未检查过同一模型的空间关系、融合和降解，不得直接批量导出完整课程。样片通过后再扩展到题图证据与全部小问。

## 视觉与因果审查清单

- [ ] 静音看前几秒，能辨认具体结构与待解决现象；开头不是片头、目录或一屏题干。
- [ ] 整体与局部来自同一模型，目标 ID、方向和相邻结构没有跳变；局部有定位线索。
- [ ] 细胞类型明确；植物、动物、酵母的结构未混用；关键双膜与磷脂双分子层有区别。
- [ ] 每句有一个主要变化，动作顺序与旁白一致；观众不用同时追两个因果过程。
- [ ] 自噬演出开放、延伸、闭合、融合、内部降解；目标不穿透完整膜，不在外部消失。
- [ ] 运输从正确一侧进入，经正确蛋白到正确终点；耗能环节与方向准确。
- [ ] 示意颗粒、比例与时间没有伪装成实测；数据图保留原指标、组别和单位。
- [ ] 机制解释、实验观察与推断明确区分；没有把 ROS 数据当成存活率。
- [ ] 看完能复述一个因果链，并能回答原先的问题；答案有题目证据支持。
- [ ] 实际配音清楚、字幕跟得上动作；音乐不盖过科学名称，移动镜头不抢关键变化。

检查结论写在样片的 `storyboard.md` 或项目审阅记录中，包括发现的问题和修改后的证据帧。`motion` 的像素变化报告只能辅助定位静止片段，不能代替这些审查。
