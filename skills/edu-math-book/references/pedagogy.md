# 教学设计要点

这个页面的节奏是：**读题 → 抓关键 → 先猜 → 掀开验证 → 跟着钢笔一步步推 → 拖滑块体会"为什么"**。写 lesson 时按这个顺序想。

## 左页
- **title**：把题目的"戏眼"说出来，而不是复述题型。好："中点里的直三棱柱""一个三次函数的三个零点"；差："立体几何第 15 题"。
- **key.scribble**：老师在页边的手写批注，说出看到题目的第一反应（"两个中点 → 中位线！""零点个数看极值符号！"）。
- **key.formula**：整道题最关键的一条定理/结论；caption 说明它在本题的作用。
- **keywords**：只放本题真正用到、学生容易模糊的 2–3 个概念，定义写成课本原话的简化版。

## 预测题
- 问最终答案（或最关键的中间量），4 个选项。
- 错误选项要"有道理地错"：漏掉一半（√2⁄2 vs 1）、端点开闭（[−2,2] vs (−2,2)）、公式记反、少算一种情况。
- `explain` 一句话点出关键，不要写完整过程。

## 演示步骤
- 每问 2–5 步，每步一个"动作"：构造辅助线、换元、判定、计算、下结论。
- **h**：这一步在干什么，口语化（"看到中点，先想中位线""把 DE 换成 BC₁"）。
- **chain**：2–4 条，每条左边是式子/结论，右边是理由（定理名、已知、上一步）。超过 4 条就拆成两步，草稿纸写不下会自动缩行但会变挤。
- 证明题最后一步写清"判定定理 ∎"，并提醒容易漏写的条件（"$DE$ ⊄ 平面 … 这一条别漏写"）。
- 每问最后一步写 `full`（考场规范写法），计算题再加 `result` 红圈答案。
- **cmap 配色要和图上一致**：同一对象在推理链、图上线条、图例里用同一种颜色。约定：
  - violet：要研究/要证的对象；orange：构造出来的辅助对象；blue / pink：涉及的平面；green：垂直关系、已知长度。
- 每一步的 `spec` 只亮这一步提到的东西，其余回到底图；用 `tag` 在图上写出这一步的结论。
- 立体题每步给 `view`，让关键的线面正对镜头、不被挡住。

## 滑块
- 有参数（角度、边长、a 的取值）的问题尽量加一个"拨回去"的步骤：`spec.a` 先拨偏，学生拖到正确值时边框变绿。
- `read` 显示随参数变化的量（角度、体积、零点个数），让学生看到"为什么是这个值"。

## 教室开场（可选）
- 适合做成"作品"展示、课堂导入。黑板文字（`intro.board`）写题号、条件、设问，最后一行可以用黄色写一句悬念。
- 需要的素材会自动拷到输出目录，不要分开移动 html 和素材。
